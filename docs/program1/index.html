도구 사용법과 작도 힌트

선분/직선: 시작점에서 끝점까지 드래그합니다. 컴퍼스: 중심과 반지름 끝점을 차례로 누른 뒤, 옮길 중심을 누르고 원 위에서 드래그하여 호를 그립니다. 폭은 유지되며, 바꾸려면 ‘새 반지름’을 누릅니다. 교점 가까이에서는 자동으로 정확한 교점에 맞춰집니다.

선분·직선 또는 각 도구로 도형을 완성하세요. 각은 ① 변 위 점 → ② 꼭짓점 → ③ 다른 변 위 점 순서로 지정합니다. ‘각 · 점 3개’ 도구는 두 번째 점을 꼭짓점으로 사용하고, 두 변을 선택한 점 너머 작도 공간 끝까지 길게 그립니다. 각 문제에서는 완성 도형이 자동 지정됩니다. 정답 도형은 기준 변이 수평인 상태로 나타납니다. 잘못 선택한 점은 ‘직전 점 취소’로 되돌리세요. 회색 직선은 시작을 돕는 보조선이며, 그 위에 선분을 덧그리면 더 진하고 굵게 표시됩니다. 정답 판정은 위치·방향·뒤집기와 관계없이 길이와 각도를 비교합니다. 길이는 3px 또는 1.5% 중 큰 값, 각도는 1° 이내의 조작 오차를 허용합니다. 정답 도형의 점을 22px 이내로 가까이 옮기면 작도한 점에 붙으며, 변이 수평·수직에서 4° 이내이면 자동 보정됩니다. 각의 두 변은 길이가 아닌 방향을 비교합니다. 작도한 점과 선·호의 교점 근처를 누르면 완성 도형의 점이 자동으로 맞춰집니다. 올가미는 작도 중에도 사용할 수 있습니다. 선택 테두리 안을 끌면 이동하고, 위쪽 원형 손잡이를 끌면 도형 중심을 기준으로 회전합니다. Shift를 누르면 15°씩 회전합니다. 예제는 상단 버튼을 눌러 자유롭게 열 수 있고, 다른 예제로 이동해도 작도 내용은 유지됩니다. 새로고침하면 예제1부터 다시 시작합니다.
